Assumptions: desktop only (1280px), English copy with a TR/EN toggle top-right, static hi-fi. Zero animation or transition; hover is a background shift on interactive rows and nothing else. Type: IBM Plex Sans for UI, IBM Plex Mono for every number and timestamp, Source Serif 4 for film titles — Wikipedia's seriousness with Letterboxd's typographic warmth. The name does the joke so the interface doesn't have to: everything below is deadpan reference-desk. Colour carries exactly four meanings, nothing decorative — red = sex scene, orange = nudity, amber = suggestive, green = clean-verified. Posters are TMDb-fed; striped placeholders here. Real film titles, invented mark data. Home has three directions — 1a 1b 1c; detail, dashboard, profile and onboarding are single proposals. Age gate, spoiler-hiding, intensity meter and the "why this exists" band are all in.
